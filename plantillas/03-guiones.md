# 03 · Guiones de reels y videos cortos

Estructura: **gancho (0–3 s) → desarrollo (3–25 s) → una sola acción**.

Reglas del gancho:
1. Un número o una escena concreta en el primer cuadro.
2. Se entiende sin sonido.
3. Sin intro ni logo.
4. El video cumple lo que promete.

## 3.1 · Diez ganchos

```
Para [MARCA], escribe 10 ganchos para el primer segundo de un reel sobre: [tema o pregunta real].
Máximo 10 palabras cada uno. Mezcla: una pregunta directa, un error común, un número concreto,
un antes y después, y una opinión que no todos comparten.
Para cada gancho: el texto en pantalla (máx. 6 palabras) y qué se ve en los primeros 2 segundos.
Marca los 3 que se entienden en 2 segundos sin sonido.
```

## 3.2 · Reel hablado a cámara (30 s)

```
Con este gancho: «[gancho]», escribe el guion de un reel de 30 segundos de [MARCA], hablado a cámara por [quién].
Tabla con columnas: tiempo · lo que se dice · texto en pantalla · lo que se ve.
- 0–3 s: el gancho tal cual.
- 3–25 s: tres puntos cortos, uno por bloque, con un ejemplo concreto del negocio.
- 25–30 s: una sola acción: [p. ej., «escríbenos "PRECIO" por WhatsApp»].
Frases que se digan en una respiración. Si falta un dato, déjalo como [DATO].
```

## 3.3 · Reel sin persona en cámara (texto + imágenes)

```
Escribe un reel de 25 a 35 segundos para [MARCA] sobre [tema], sin persona en cámara:
texto grande en pantalla, imágenes fijas con movimiento suave y [voz en off / solo música].
Tabla con columnas: toma · segundos · texto en pantalla (máx. 7 palabras) · voz (si hay) · imagen clave.
Máximo 8 tomas. Una imagen clave por toma, descrita para generarla después
(sujeto, acción, encuadre, luz, estilo). Las imágenes van sin texto ni logos.
La primera toma tiene que funcionar como gancho aunque el video esté en silencio.
```

## 3.4 · Adaptar una referencia

```
Te paso la transcripción de un video que funcionó: [pega el texto o el resumen].
Adáptalo para [MARCA] en español nativo de Perú. No lo traduzcas literal:
cambia ejemplos, expresiones y situaciones por unas de aquí y del rubro del cliente.
Mantén la estructura (gancho, ritmo, giro, cierre) y explícame en 3 líneas por qué funciona esa estructura.
No copies frases textuales del original.
```

## 3.5 · Serie de 5 videos

```
Propón una serie de 5 reels para [MARCA] con un mismo formato que se repite
(p. ej., «Error de la semana», «Lo que nadie te dice de [rubro]»).
Para cada capítulo: gancho, 3 puntos y cierre.
Varía la apertura en cada capítulo para que no parezca plantilla.
```

## 3.6 · Crítica del guion

```
Revisa tu guion como un editor exigente:
1. ¿El gancho se entiende sin sonido?
2. ¿Cumple lo que promete?
3. ¿Alguna frase suena a anuncio o a IA?
4. ¿Sobra algún segundo?
5. ¿La acción final es una sola y es clara?
Dame la versión corregida y la lista de cambios.
```

## 3.7 · Del guion al texto para subtítulos

```
Del guion aprobado, saca el texto de los subtítulos en bloques de 1 a 3 palabras, una línea por bloque,
sin signos de más. Marca con * la palabra clave de cada frase (va resaltada en la edición).
```
