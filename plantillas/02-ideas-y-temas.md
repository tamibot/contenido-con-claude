# 02 · Ideas y temas

Regla: **cada idea parte de algo real.** Una pregunta, un error, un dato, algo que pasó.

## 2.1 · Desde preguntas reales

```
Estas son preguntas reales que recibe [MARCA] (sin nombres de quién las hizo):
1. [pregunta]
2. [pregunta]
3. [pregunta]

Dame 20 ideas de contenido para Instagram y TikTok que respondan a estas preguntas.
Para cada idea: título de trabajo (máx. 8 palabras), formato (reel, carrusel o post)
y objetivo (educar, mostrar, vender o conversar). Mezcla los cuatro objetivos.
Nada de ideas que sirvan igual para cualquier marca.
Al final, marca las 5 mejores y por qué, en una línea cada una.
```

## 2.2 · Desde las objeciones

```
Antes de comprar, los clientes de [MARCA] dicen: «[objeción 1]», «[objeción 2]», «[objeción 3]».
Dame 3 ideas de contenido por objeción que la respondan sin sonar a defensa:
una que eduque, una que muestre (proceso, producto, caso) y una que cuente una historia corta.
```

## 2.3 · Desde un dato del negocio

```
Dato real de [MARCA]: [p. ej., «este mes entregamos 120 pedidos», «el 70 % pide el combo grande»].
Dame 8 ideas de contenido que usen este dato. El dato va tal cual, sin redondear ni exagerar.
Para cada una, el gancho (máx. 10 palabras) con el número en el primer cuadro.
```

## 2.4 · Desde la competencia

```
Estos son temas que publica la competencia de [MARCA]:
- [competidor 1]: [qué publica]
- [competidor 2]: [qué publica]

1. ¿Qué temas se repiten en todos? (ahí está saturado)
2. ¿Qué preguntas del cliente nadie está respondiendo?
3. Dame 10 ideas para [MARCA] en ese hueco, con el ángulo propio de la marca.
No copies temas ni frases de la competencia.
```

## 2.5 · Temas por pilar para un mes

```
Para [MARCA], dame 5 temas por cada pilar para [mes]:
- Educa (responde dudas, enseña algo útil)
- Muestra (producto, proceso, detrás de cámaras, casos)
- Vende (oferta con precio y una acción)
- Conversa (opinión, pregunta, encuesta)
Ten en cuenta estas fechas del mes: [fechas].
Para cada tema, el mejor formato y por qué en 5 palabras.
```

## 2.6 · Filtro rápido

```
Revisa estas ideas: [pega la lista].
Quédate solo con las que cumplen las tres:
1. Es útil o plantea una tensión que quiero ver resuelta.
2. Es de esta marca (otra marca no la podría publicar igual).
3. Se puede mostrar algo concreto (producto, número, escena, antes y después).
Dime cuáles descartas y por qué, en una línea cada una.
```
