# 04 · Copys para posts y anuncios

Reglas: comercial y no poético; una idea por pieza; precio claro cuando hay; leer en voz alta antes de aprobar.

## 4.1 · Post orgánico

```
Escribe el texto de un post de Instagram para [MARCA] sobre: [tema].
- Primera línea: el gancho, que se lea antes del «… más».
- Cuerpo: máx. 80 palabras, párrafos de 1 a 2 líneas.
- Cierre: una pregunta para comentar o una acción concreta.
- 3 a 5 hashtags específicos del rubro y de la ciudad.
Dame 3 versiones: corta (máx. 30 palabras), media y una con mini historia.
```

## 4.2 · Anuncio de Meta (Facebook e Instagram)

```
Escribe 5 variantes de anuncio para Meta de [MARCA].
Oferta: [qué, precio, condiciones reales]. Público: [a quién]. Destino: [WhatsApp / web / formulario].
Para cada variante: texto principal (máx. 125 caracteres), título (máx. 40), descripción (máx. 30) y botón.
Un ángulo distinto por variante: precio, ahorro de tiempo, miedo a equivocarse, prueba social, urgencia real.
Nada de cifras ni testimonios que no estén en la ficha. Nada de urgencia falsa.
Al final, dime cuáles 2 probarías primero y por qué.
```

## 4.3 · Versión larga para anuncio con más texto

```
Con la variante [n.º], escribe una versión larga del texto principal (máx. 90 palabras):
problema en una línea → qué recibe el cliente → cómo funciona en 3 pasos → precio → una acción.
```

## 4.4 · Historias (stories)

```
Escribe una secuencia de 4 historias para [MARCA] sobre [tema u oferta]:
1 gancho o pregunta · 2 contexto · 3 la oferta o el dato · 4 acción (sticker de enlace, encuesta o «responde con…»).
Máximo 12 palabras por historia. Sugiere qué sticker usar en cada una.
```

## 4.5 · Primer mensaje de WhatsApp tras un anuncio

```
Alguien escribió a [MARCA] por WhatsApp desde el anuncio de [oferta].
Escribe la primera respuesta (máx. 50 palabras): saludo corto, confirma la oferta con su precio,
y una sola pregunta para avanzar. Sin listas, sin emojis de más.
Dame 2 versiones: una más cercana y una más directa.
```

## 4.6 · Respuestas a comentarios

```
Estos son comentarios reales en publicaciones de [MARCA] (sin nombres):
[pega los comentarios].
Escribe una respuesta para cada uno, máx. 25 palabras, en el tono de la marca.
Si es una queja, primero reconoce el problema y lleva la conversación a privado.
Si piden precio, dalo si está en la ficha; si no, invítalos a escribir por WhatsApp.
```

## 4.7 · Revisar un copy

```
Revisa este copy contra la ficha de marca: [pega el copy].
1. ¿Hay algún dato que no esté en la ficha?
2. ¿Usa alguna palabra prohibida o alguna muletilla de IA?
3. ¿Tiene una sola idea y una sola acción?
4. ¿Se lee bien en voz alta?
Dame la versión corregida, con los cambios marcados.
```
